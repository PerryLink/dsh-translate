# dsh-translate

**पूरे इंटरफ़ेस का अनुवाद अपनी भाषा में करें — अपने ही DSH मॉडल रूट के साथ, और कोड, पथ, कमांड या उत्पाद नामों को छुए बिना।**

DeepSeek Harness के लिए एक एंड-टू-एंड अनुवादक। ब्राउज़र वाला आधा हिस्सा पृष्ठ के टेक्स्ट पर चलता है, हर उस स्पैन को मास्क करता है जो जस का तस रहना चाहिए (कोड ब्लॉक और इनलाइन कोड, फ़ाइल पथ, शेल कमांड, URL, पहचानकर्ता, संस्करण, हैश, संख्याएँ, उत्पाद नाम) और उन्हें `⟦n⟧` प्लेसहोल्डर में बदल देता है, फिर शेष गद्य को होस्ट वाले हिस्से को भेजता है। होस्ट **उसी मॉडल रूट से अनुवाद करता है जो आपका वर्तमान सत्र पहले से उपयोग करता है**, ब्राउज़र प्लेसहोल्डर बहाल करता है और परिणाम को उन्हीं टेक्स्ट नोड्स में वापस लिखता है। मूल प्रति मेमोरी में रहती है; **Original** पर एक क्लिक पृष्ठ को बहाल कर देता है।

डिज़ाइन से केवल-प्रदर्शन: सत्र लॉग, कार्यस्थान और DSH कॉन्फ़िग कभी नहीं लिखे जाते। ट्रांसक्रिप्ट ठीक वही रखता है जो मॉडल ने कहा था।

> **0.3.0 से, `dsh-translate` पूर्ण-पृष्ठ अनुवादक है।** पहले वाला "विक्रेता पैरामीटर
> मैपिंग + नियतात्मक JSON रिपेयर" प्लगइन अब
> [`dsh-param-repair`](https://github.com/PerryLink/dsh-param-repair) (1.0.0) है। यदि आपने
> 0.2.x से अपग्रेड किया है और वह व्यवहार चाहिए, तो `dsh-param-repair` इंस्टॉल करें और इस पंक्ति को हटाएँ; पुरानी कॉन्फ़िग कुंजियाँ
> (`repair.*`, `rosettaDataPath`) नए प्लगइन द्वारा अनदेखी की जाती हैं और प्रोफ़ाइल को विफल नहीं करतीं।

## क्या अनुवादित होता है

| अनुवादित | जस का तस रखा गया |
|---|---|
| सहायक गद्य, तर्क सारांश, टूल आउटपुट गद्य | फ़ेंस्ड और इनलाइन कोड (`code` / `pre`) |
| Markdown शीर्षक, सूचियाँ, तालिकाएँ, लिंक लेबल | फ़ाइल पथ, globs, कमांड और फ़्लैग, URL, ईमेल |
| बटन, लेबल, सेटिंग्स पाठ | JSON कुंजियाँ, env vars, `dsh-*` / `snake_case` / `camelCase` पहचानकर्ता |
| अन्य प्लगइन्स का पाठ (छिपे पॉपओवर सहित) | संस्करण, हैश, सादे संख्याएँ, और `⟦n⟧` प्लेसहोल्डर |
| — | उत्पाद नाम: DeepSeek Harness, Cordis, npm, GitHub, Gitee, GitCode, Phocinae, PerryLink, … |

जिस टेक्स्ट नोड में कोई गद्य नहीं बचता (उदाहरण के लिए कोई पथ या कोड स्पैन), उसे छोड़ दिया जाता है। यदि मॉडल कोई प्लेसहोल्डर खो देता है, उसे फिर से क्रमांकित करता है या गढ़ लेता है, तो वह खंड अपना मूल टेक्स्ट रखता है, बजाय पृष्ठ में आधा-मास्क किया गया स्ट्रिंग लिखने के।

## इंस्टॉल

```sh
dsh plugin --profile <name> add dsh-translate
```

Web GUI को पुनः लोड करें: नीचे-दाएँ एक **Translate** पिल दिखाई देता है। पृष्ठ का अनुवाद करने के लिए एक बार क्लिक करें (यह **Original** हो जाता है); बहाल करने के लिए फिर क्लिक करें।

## आवश्यकताएँ

अनुवाद **आपके अपने मॉडल** का उपयोग करता है, कोई बंडल की गई कुंजी नहीं और कोई बंडल किया गया प्रदाता नहीं:

1. प्रोफ़ाइल को एक `llm` सेवा और काम करता हुआ प्रदाता चाहिए (एक सामान्य चैट पहले ही इसे सिद्ध कर देता है);
2. रूट डिफ़ॉल्ट रूप से किसी लाइव सत्र द्वारा दर्ज किए गए नवीनतम `request/header` का उपयोग करता है, इसलिए पहले एक संदेश भेजें — या कॉन्फ़िग में `provider` / `model` पिन करें।

रूट के बिना नियंत्रण कारण दिखाता है (उदाहरण के लिए `no model route: …`) और पृष्ठ को छोड़ दिया जाता है।

## कॉन्फ़िगरेशन

प्रत्येक कुंजी एक Schemastery फ़ील्ड है; अमान्य मान प्रोफ़ाइल लोड को ज़ोरदार ढंग से विफल कर देता है।

| कुंजी | डिफ़ॉल्ट | अर्थ |
|---|---|---|
| `enabled` | `true` | मुख्य स्विच; `false` कुछ भी माउंट नहीं करता |
| `targetLang` | `''` | लक्ष्य भाषा; रिक्त होने पर Web GUI लोकेल का अनुसरण करता है (जब UI अंग्रेज़ी में हो तो ब्राउज़र भाषा) |
| `provider` / `model` | `''` | वैकल्पिक स्पष्ट रूट; **दोनों या कोई नहीं**; रिक्त होने पर नवीनतम सत्र रूट विरासत में मिलता है |
| `maxSegments` | `40` | प्रति मॉडल कॉल खंड (1–200) |
| `maxChars` | `6000` | प्रति मॉडल कॉल अक्षर (200–40000) |
| `timeoutMs` | `60000` | प्रति-कॉल समय-सीमा (1000–600000) |
| `glossary` | `[]` | जस का तस रखने के लिए अतिरिक्त शब्द |

उदाहरण: जापानी बाध्य करें और आंतरिक उत्पाद नामों की रक्षा करें:

```yaml
- id: dsh-translate
  name: dsh-translate
  config:
    enabled: true
    targetLang: ja
    glossary: [Acme Ledger, Internal Ticketing]
```

## लागत और गोपनीयता

- **मांग पर, केवल पृष्ठ का टेक्स्ट (छिपे पॉपओवर खुलने से पहले अनुवादित हो जाते हैं)**: नियंत्रण पर क्लिक होने तक पृष्ठभूमि में कुछ नहीं चलता; इसे बंद करने पर काम रुक जाता है।
- **कैश**: वही स्रोत खंड (वही लक्ष्य भाषा) एक बार अनुवादित होता है और ब्राउज़र `localStorage` में कैश होता है (अधिकतम 600 प्रविष्टियाँ); साइट डेटा साफ़ करने पर यह साफ़ हो जाता है।
- **मशीन से क्या बाहर जाता है**: केवल वह गद्य जिसमें संरक्षित स्पैन मास्क किए गए हैं, आपके द्वारा कॉन्फ़िगर किए गए प्रदाता को भेजा जाता है; पथ, कोड, कमांड और कुंजी-जैसे पहचानकर्ता अनुवाद योग्य टेक्स्ट के रूप में नहीं भेजे जाते।
- **कोई स्थायीकरण नहीं**: अनुवाद DOM और ब्राउज़र कैश में रहते हैं; सत्र लॉग, कार्यस्थान और DSH कॉन्फ़िग अछूते रहते हैं।
- **कोई क्रेडेंशियल नहीं**: प्लगइन कभी API कुंजी नहीं पढ़ता या संग्रहीत नहीं करता; प्रमाणीकरण होस्ट प्रदाता कॉन्फ़िगरेशन के पास ही रहता है।

## ज्ञात सीमाएँ

- अनुवाद रेंडर परत पर होता है। जब React किसी नोड को पुनः रेंडर करता है तो वह मूल को वापस लिख देता है; MutationObserver बिना किसी अन्य मॉडल कॉल के कैश किए गए अनुवाद को फिर से लागू कर देता है। एक संक्षिप्त झिलमिलाहट संभव है।
- स्ट्रीमिंग टेक्स्ट बदलता रहता है, इसलिए प्लगइन 350 ms की शांत अवधि के बाद अनुवाद करता है; लंबे स्ट्रीमिंग उत्तरों का अनुवाद थोड़ा बाद में मिलता है।
- छवियों, Canvas या PDF पूर्वावलोकनों के लिए कोई OCR नहीं।
- छिपे हुए तत्व (`display:none` पॉपओवर) भी देखे जाते हैं, इसलिए पॉपओवर खुलने पर पहले से अनुवादित होता है और दूसरी मॉडल कॉल की ज़रूरत नहीं होती।
- GUI स्वयं पहले से आठ लोकेल देता है (en / zh / ja / es / fr / de / ru / pt); यह प्लगइन **सामग्री** और तृतीय-पक्ष प्लगइन्स के अंग्रेज़ी पाठ का अनुवाद करता है, और अंतर्निहित लोकेल सिस्टम को प्रतिस्थापित नहीं करता।

## विकास

```sh
pnpm install
pnpm test        # 21 cases: masking/restore, placeholder checks, batching, route resolution, jsdom DOM behaviour, descriptor parity
pnpm run lint
```

लेआउट:

- `index.mjs` — होस्ट प्रवेश (Config + सेवा माउंट)
- `lib/service.mjs` — `translatePage` Typert सेवा (status / translate)
- `lib/engine.mjs` — प्रॉम्प्ट, बैचिंग, पार्सिंग, प्लेसहोल्डर सत्यापन (कोई cordis नहीं, कोई DOM नहीं; यूनिट-परीक्षित)
- `lib/wire.mjs` — दोनों फलकों द्वारा साझा किए गए इनवोकेशन डिस्क्रिप्टर
- `typert.host.mjs` — होस्ट Typert मैनिफ़ेस्ट
- `client/index.js` — हस्तलिखित क्लाइंट बंडल: DOM वॉक, मास्किंग, कैश, फ़्लोटिंग नियंत्रण
